FAQ

Questions, answered.

The basics, without a wall of text.

What is Torn Tools?+

Torn Tools is the public home for Congerie's Torn client and future player utilities.

What is the Congerie client?+

It is an Android companion that connects to Torn's API and presents useful player information in a focused interface.

Is the client free?+

The current build is a private beta. Release and access details will be posted here when the public build is ready.

How do updates work?+

The Android client includes an automatic update system. This website is designed to host the public release manifest and APK.
